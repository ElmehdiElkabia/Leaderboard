# Moroccan 1337 Campus IDs

## Campus Information
- **Benguerir**: ID = 21
- **Rabat**: ID = 75  
- **Tétouan**: ID = 55
- **Khouribga**: ID = [To be identified]

## Usage
These IDs can be used to filter students and data for specific Moroccan campuses in the 42 API.

## API Endpoints
- Get campus details: `/v2/campus/{id}`
- Get campus users: `/v2/campus/{id}/users`
- Filter users by campus: `/v2/users?filter[campus_id]={id}`

## Notes
- Data obtained from `/v2/campus` endpoint
- IDs are consistent across the 42 API
- Can be used for campus-specific leaderboards and filtering
